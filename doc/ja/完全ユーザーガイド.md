## 概要と特徴

本システムは、E(3)等変性を数学的に厳密に保持した拡散モデルによって、3次元分子構造および結晶構造を生成します。

### 主要機能の完全リスト

#### 1. 分子生成機能
- **無条件生成**: データセット分布から新規分子を生成
  - QM9データセット対応（約134,000分子）
  - GEOM-Drugsデータセット対応（医薬品様分子）
  - カスタムASEデータベース対応
  
- **条件付き生成**: 物理化学的性質を指定して生成
  - alpha（分極率）: 0-200 Bohr³
  - gap（HOMO-LUMOギャップ）: 0-15 eV
  - homo（HOMO準位）: -15 to 0 eV
  - lumo（LUMO準位）: -5 to 5 eV  
  - mu（双極子モーメント）: 0-10 Debye
  - Cv（熱容量）: 5-50 cal/mol·K
  - 複数性質同時条件付け可能

- **分子記述子条件付け**: より詳細な分子特性で制御
  - molecular_weight（分子量）: 任意のDa値
  - pi_conjugation_ratio（π共役比率）: 0.0-1.0
  - atom_types_encoding（原子タイプ分布）: 多次元ベクトル
  - functional_groups_encoding（官能基）: SMARTSパターンベース

#### 2. 結晶構造生成機能
- **ホモクリスタル生成**: 単一分子種の周期構造
  - 230空間群すべてに対応
  - 格子パラメータ自動学習
  - 周期境界条件（PBC）厳密実装
  
- **結晶条件付け**:
  - 空間群指定（1-230番）
  - 密度制御（0.5-2.0 g/cm³）
  - 分子特徴による制約
  - 格子定数範囲指定

#### 3. 評価・解析機能
- **構造妥当性評価**:
  - 原子レベル安定性チェック
  - 分子レベル安定性検証
  - RDKit妥当性検証
  - 結合長分布解析

- **品質メトリクス**:
  - Uniqueness（ユニーク性）
  - Novelty（新規性）
  - Validity（妥当性）
  - Property distribution matching（性質分布一致度）

### 理論的保証

#### E(3)等変性の厳密な実装
本システムのすべての操作は、3次元ユークリッド群E(3)に対して等変です：

```
∀ g ∈ E(3), f(g·x) = g·f(x)
```

これは以下を保証します：
- **並進不変性**: 分子の位置に依存しない
- **回転不変性**: 分子の向きに依存しない
- **反転対称性**: 鏡像異性体を正しく扱う

#### Fallbackなしの設計原則
**重要**: 本システムは一切のfallback（ごまかし）を含みません：
- すべてのエラーは明示的に検出され報告される
- 不正な入力は例外を発生させる
- 近似を使用する場合は明示的に文書化される
- すべての数値計算は理論的に正当化される

**2. pi_conjugation_ratio (π共役比率)**
```python
def compute_pi_conjugation_ratio(atoms):
    \"\"\"π共役系の割合を推定\"\"\"
    atomic_numbers = atoms.get_atomic_numbers()
    
    # sp2混成可能な原子（C, N, O）の数
    sp2_candidates = sum(1 for z in atomic_numbers if z in [6, 7, 8])
    
    # 重原子総数
    heavy_atoms = sum(1 for z in atomic_numbers if z > 1)
    
    if heavy_atoms == 0:
        return 0.0
    
    # 簡略化した推定（実際はより詳細な解析が必要）
    return sp2_candidates / heavy_atoms

ratio = compute_pi_conjugation_ratio(benzene)
print(f"π共役比率: {ratio:.2f}")
```

**3. atom_types_encoding (原子タイプ分布)**
```python
def compute_atom_types_encoding(atoms, atom_types=[1, 6, 7, 8, 9]):
    \"\"\"原子タイプの one-hot エンコーディング\"\"\"
    atomic_numbers = atoms.get_atomic_numbers()
    encoding = np.zeros(len(atom_types))
    
    for i, atom_type in enumerate(atom_types):
        encoding[i] = (atomic_numbers == atom_type).sum()
    
    # 正規化
    encoding = encoding / encoding.sum() if encoding.sum() > 0 else encoding
    
    return encoding

encoding = compute_atom_types_encoding(water)
print(f"原子タイプ分布: {encoding}")
# 出力例: [0.667, 0.000, 0.000, 0.333, 0.000]  # H: 66.7%, O: 33.3%
```

**4. functional_groups_encoding (官能基検出)**
```python
from rdkit import Chem
from rdkit.Chem import AllChem

def compute_functional_groups(mol):
    \"\"\"SMARTS パターンで官能基を検出\"\"\"
    
    functional_groups = {
        'hydroxyl': '[OH]',                    # ヒドロキシル基
        'carbonyl': '[CX3]=[OX1]',            # カルボニル基
        'carboxyl': '[CX3](=O)[OX2H1]',       # カルボキシル基
        'amine': '[NX3;H2,H1;!$(NC=O)]',      # アミン
        'amide': '[NX3][CX3](=[OX1])[#6]',    # アミド
        'ether': '[OD2]([#6])[#6]',           # エーテル
        'ester': '[#6][CX3](=O)[OX2][#6]',    # エステル
        'aromatic': 'c',                       # 芳香環
        'nitro': '[NX3](=O)=O',               # ニトロ基
        'sulfide': '[SX2]([#6])[#6]',         # スルフィド
    }
    
    encoding = {}
    for group_name, smarts in functional_groups.items():
        pattern = Chem.MolFromSmarts(smarts)
        if pattern:
            matches = mol.GetSubstructMatches(pattern)
            encoding[f'fg_{group_name}'] = len(matches)
        else:
            encoding[f'fg_{group_name}'] = 0
    
    return encoding

# 使用例
mol = Chem.MolFromSmiles('CC(=O)OCC')  # 酢酸エチル
groups = compute_functional_groups(mol)
for group, count in groups.items():
    if count > 0:
        print(f"  {group}: {count}")
# 出力:
#   fg_ester: 1
```

### パラメータの詳細説明

#### モデルアーキテクチャ

**--model STR**
モデルのタイプを指定します。

選択肢:
- `egnn_dynamics`: EGNN (E(n) Equivariant GNN) - **推奨**
  - E(3)等変性を保証
  - メッセージパッシングベース
  - 座標と特徴を同時に更新
  
- `gnn_dynamics`: 標準GNN（非等変）
  - 比較用ベースライン
  - 等変性なし

- `schnet`: SchNet アーキテクチャ
  - 連続フィルター畳み込み
  - 距離ベースの相互作用

**--nf INT**
隠れ層の次元数（number of features）。

推奨値:
- 小規模実験: 64-128
- 標準: 192-256
- 大規模: 512

**効果:**
- 大きいほど表現力が高い
- メモリ使用量とトレードオフ
- 256で十分な性能

**--n_layers INT**
ネットワークの層数。

推奨値:
- 最小: 3
- 標準: 6
- 高品質: 9
- 最大: 12（オーバーフィッティングの可能性）

**効果:**
- 多いほど長距離相互作用を捉える
- 深すぎると勾配消失の可能性

**--attention BOOL**
アテンション機構の使用。

```bash
--attention True  # 推奨
--attention False  # メモリ削減時
```

**効果:**
- True: より柔軟な表現、高品質
- False: 高速、省メモリ

#### 拡散設定

**--diffusion_steps INT**
拡散過程のステップ数。

推奨値:
- テスト: 100
- 標準: 500
- 高品質: 1000

**トレードオフ:**
- 多い: 高品質だがサンプリング遅い
- 少ない: 高速だが品質低下

**--diffusion_noise_schedule STR**
ノイズスケジュールの種類。

選択肢:
- `polynomial_2`: 多項式スケジュール（次数2） - **推奨**
  - QM9で最良の結果
  - 初期ステップで急速なノイズ増加
  
- `cosine`: コサインスケジュール
  - より滑らかな減衰
  - GEOM-Drugsで良好
  
- `learned`: 学習可能スケジュール
  - パラメータとして学習
  - 実験的機能

**--diffusion_noise_precision FLOAT**
ノイズ精度（最小SNR値）。

推奨値: `1e-5`

**効果:**
- 小さいほど数値安定
- 大きすぎると情報損失

**--diffusion_loss_type STR**
損失関数のタイプ。

選択肢:
- `l2`: シンプルL2損失 - **推奨**
  - 計算効率的
  - 良好な結果
  
- `vlb`: 変分下界
  - 理論的に厳密
  - 計算コスト高

#### 訓練設定

**--n_epochs INT**
訓練エポック数。

推奨値:
- クイックテスト: 10-100
- 標準訓練: 1000
- 高品質: 3000

**--batch_size INT**
バッチサイズ。

推奨値と要件:
- 16: 8GB VRAM
- 32: 12GB VRAM
- 64: 16GB VRAM - **推奨**
- 128: 32GB VRAM

**--lr FLOAT**
学習率。

推奨値: `1e-4`

**調整ガイド:**
- 収束しない → 下げる (5e-5)
- 収束が遅い → 上げる (2e-4)
- NaNが発生 → 下げる (5e-5)

**--ema_decay FLOAT**
Exponential Moving Averageの減衰率。

推奨値: `0.9999`

**効果:**
- EMAモデルが通常より安定
- 評価時にEMAを使用
- 0に近い: 更新が速い
- 1に近い: より保守的

**--normalize_factors FLOAT,FLOAT,FLOAT**
座標・特徴・電荷の正規化係数。

推奨値:
- 無条件生成: `1,4,10`
- 条件付き生成: `1,8,1`

フォーマット: `x_factor,h_factor,charge_factor`

**--test_epochs INT**
評価を実行するエポック間隔。

推奨値:
- 開発中: 5-10
- 本番: 20-50

**--n_stability_samples INT**
評価時に生成するサンプル数。

推奨値:
- クイックチェック: 100
- 標準: 500-1000
- 詳細評価: 10000
