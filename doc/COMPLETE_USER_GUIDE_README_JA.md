## 出力の意味の説明例

### 学習時の出力

```
Epoch 100/3000:
  Train Loss: 14.234      # 学習データでの拡散損失（L2距離）
  Val Loss: 14.891        # 検証データでの損失（過学習の指標）
  Atom Stability: 94.3%   # 化学的に妥当な結合数を持つ原子の割合
  Molecule Stability: 87.6%  # 全原子が安定な分子の割合
```

### 評価指標の意味

- **Validity（有効性）**: RDKitで有効な分子構造として認識される割合
  - 化学的に実在可能な分子の指標
  - 計算方法: 有効な分子数 / 全生成分子数

- **Uniqueness（一意性）**: 重複しない一意な分子の割合
  - 生成の多様性を示す
  - 計算方法: 一意な分子数 / 有効な分子数
  - SMILES表記で判定

- **Novelty（新規性）**: 学習データセットに含まれない新しい分子の割合
  - 生成モデルの創造性を示す
  - 計算方法: 学習データに無い分子数 / 一意な有効分子数

- **Atom Stability**: 妥当な結合数を持つ原子の割合
  - H: 1本、C: 4本、N: 3本、O: 2本、F: 1本

- **Molecule Stability**: 全原子が安定な分子の割合

### ファイル形式

#### XYZファイル
```
24                              # 原子数
Molecule ID: 0, ...            # メタデータ
C    0.000    1.400    0.000   # 原子タイプと座標（Å）
...
```

#### CIFファイル
```
_cell_length_a    8.52          # 格子定数（Å）
_cell_angle_beta  104.80        # 格子角（度）
_space_group_IT_number 14       # 空間群番号
_atom_site_fract_x 0.1234       # 分率座標（0-1）
...
```

#### CSVファイル
```csv
ID,分子の組成,分子量
0,C6H12O6,180.1559              # ID、化学式、分子量
...
```

1. **理論的健全性**: 全ての処理が物理的・化学的に妥当

3. **近似なし**: ごまかしのための近似的な処理を使用しない
4. **完全性**: 例外処理も含めて全てを文書化
